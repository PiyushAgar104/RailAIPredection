> **RailPredict AI** is a next-generation (Year 2050-style) Indian Railways AI-powered delay prediction command center. Built with React 18, WebGL 3D locomotive rendering, XGBoost machine learning algorithms, and interactive spatial network visualizers.

---

## ✨ Key Features

### 1. 🚄 3D WebGL Locomotive Visualizer
- Hardware-accelerated 3D rendering of the **IR-WAP7 Cyber-X** electric locomotive using **Three.js**.
- Features metallic body shaders, blue neon light trails, LED headlights, pantograph electric arcs, and orbit camera controls.

### 2. 🤖 AI Delay Inference Engine
- Interactive train prediction card supporting premier Indian trains (*12951 Mumbai Rajdhani*, *20901 Vande Bharat*, *12002 Shatabdi*, etc.).
- Evaluates satellite fog index, track congestion queues, and historical speed variance.

### 3. 📊 Holographic SaaS Command Center Dashboard
- Stat Cards: **Total Trains (13,000+)**, **Prediction Accuracy (92%)**, **Average Delay (28 Mins)**, **Live Predictions (2,500+)**.
- Recharts visualizations for 24-hour delay trends, zone punctuality, and route congestion heatmaps.

### 4. 🗺️ Interactive Spatial India Railway Map
- SVG map of India displaying major Golden Quadrilateral trunk corridors and station nodes (Delhi, Mumbai, Howrah, Chennai, Bengaluru, Ahmedabad, Varanasi).

### 5. 💬 RailMind AI Chatbot Assistant
- Floating assistant answering delay queries, fog weather forecasts, and corridor congestion status.
